Mi_Proyecto_Optimus

Es un programa es enfocado para ayudar a controlar facturas, incluyendo datos de proveedores, incluye login por medio de credenciales. 

Este programa está dirigido para pequeñas y medianos proveedores.

Esta elaborado con lenguajes como PHP,HTML,CSS y base de datos MariaDB por medio de XAMPP como servior local.
